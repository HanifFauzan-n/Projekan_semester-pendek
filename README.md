# Zelatan Cell — Backend (Spring Boot)

REST API, keamanan, pembayaran Xendit, laporan, dan AI chat admin untuk aplikasi Zelatan Cell.
Dokumentasi lengkap (fitur, konfigurasi, database, cara menjalankan) ada di
[README utama](../README.md).

Ringkas:

```bash
cp .env.example .env      # isi kredensial
mvn spring-boot:run       # http://localhost:8080
```
